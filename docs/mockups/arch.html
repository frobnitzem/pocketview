description

A JSON viewer to keep in your back pocket. Every element of the tree is assigned a display variant by a bottom-up size calculation, and an automatic layout pass decides what is shown, where, and how; whatever does not fit is folded into borders, chips and breadcrumbs so that navigation never gets stuck.
